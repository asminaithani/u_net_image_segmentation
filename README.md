# U-Net Image Segmentation for Optic Disc Detection

## Project Overview

This project implements a **U-Net deep learning model** for **optic disc image segmentation**. The model is trained to identify and segment the optic disc region from retinal/fundus images using image segmentation techniques.

## Objectives

* Perform optic disc segmentation from retinal images
* Train a U-Net model for medical image segmentation
* Evaluate model performance using segmentation metrics

## Technologies Used

* Python
* PyTorch
* OpenCV
* NumPy
* Matplotlib
* Google Colab

## Model Architecture

The project uses the **U-Net architecture**, a convolutional neural network (CNN) widely used for biomedical image segmentation tasks.

## Files in Repository

* `notebook.ipynb` → Complete implementation and training code
* `metrics_summary.png` → Model performance and evaluation results
* `optic_disc_unet.pth` → Trained model weights *(not uploaded due to file size limitation)*

## Results

The model successfully performs optic disc segmentation and generates evaluation metrics for performance analysis.
